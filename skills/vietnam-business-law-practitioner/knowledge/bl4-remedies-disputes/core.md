# BL4 — Breach / Remedies / Evidence / Disputes

## Owns

Breach/liability classification after BL3 state; excuse; remedy availability; notice; mitigation; loss/proof; evidence preservation; limitation/deadlines; settlement/dispute/forum posture.

## Does not own

What contract/obligation exists (BL3), governing-law/treaty resolution (BL8), employment classification (BL6), regulatory legality (BL7).

## Activate when

There is non-performance, defective/late performance, threatened breach, notice/claim, loss, evidence urgency, settlement, or dispute escalation.

## Core distinctions

- deviation ≠ actionable breach;
- breach ≠ liability;
- liability ≠ every remedy available;
- force majeure ≠ generic bad event;
- hardship ≠ force majeure;
- penalty ≠ damages ≠ late-payment interest;
- having a remedy ≠ exercising it correctly;
- negotiation should not silently waive rights or deadlines.

## Decision procedure

1. Receive obligation/performance state from BL3.
2. Classify breach/materiality and attribution.
3. Test contractual/statutory excuse and risk allocation.
4. Preserve position: notice, objection, evidence, mitigation, deadlines.
5. Identify business objective: preserve performance, recover money, exit, reduce loss, protect assets, or settle.
6. Map only legally available remedies.
7. Build loss/proof ledger where damages are material.
8. Choose dispute/settlement path and urgent protection only as needed.
9. If settlement changes obligations, return the new transaction state to BL3.

## Failure modes

Any delay treated as termination right; force-majeure keyword matching; penalty ceiling/base guessed from memory; alleged loss accepted without causation/proof; mitigation ignored; notice treated as paperwork; negotiation allowed to consume limitation; governing law/forum/arbitration/enforcement collapsed.
