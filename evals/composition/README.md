## What must be evaluated

Do not score only final prose.

Where material, the harness/reviewer must establish:

1. initial BL1 route hypothesis;
2. activated and intentionally skipped BL tracks;
3. late-route activation;
4. accountable owner for each material proposition;
5. Authority Resolver calls, temporal anchors, freshness and owner applicability decision;
6. owner-bound JIT specialist invocation and return path;
7. contradiction/reclassification transitions;
8. typed `DEPENDS_ON` invalidation versus `SIGNALS` / `FEEDBACK` review triggers;
9. composition conflicts;
10. per-action readiness.

A plausible legal answer reached through the wrong path is an architecture failure.

The v0.2 contracts are a **repair candidate**, not a frozen runtime. Phase 4 becomes freeze-ready only after adversarial runtime evidence demonstrates the expected paths/state transitions under perturbation.
